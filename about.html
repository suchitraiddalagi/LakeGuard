ABOUT THE PROJECT

Smart Lake Pollution Monitoring System

An educational website demonstrating how water-quality information can be presented, analyzed, and used to illustrate pollution alerts.

PROJECT OVERVIEW

Why Lake Pollution Monitoring Matters

Lakes are important sources of water and support aquatic plants, animals, and surrounding communities. Pollution caused by sewage, industrial discharge, agricultural runoff, and improper waste disposal can negatively affect lake ecosystems.

Monitoring water-quality parameters can help identify changes that may require further investigation. Digital dashboards can make this information easier to understand by presenting measurements, summaries, and notifications in one place.

LakeGuard demonstrates these ideas using simulated readings. It is a website prototype, not a real-time environmental monitoring system.

🌊

Our Project Goal

Demonstrate how a digital platform could organize water-quality readings and communicate potential concerns through a dashboard, analysis page, and alert interface.

PROJECT OBJECTIVES

What This Project Aims to Achieve

The website prototype focuses on presenting environmental information clearly and simply.

📊

Display Water-Quality Data

Present example readings for pH, turbidity, dissolved oxygen, and water temperature.

🔍

Analyze Readings

Demonstrate how different water-quality parameters can be reviewed and compared.

🔔

Illustrate Pollution Alerts

Show how a system could display notifications when readings meet predefined alert conditions.

🌱

Promote Awareness

Explain why monitoring water quality and preventing pollution are important for lake ecosystems.

MONITORED PARAMETERS

What Does the Website Display?

These parameters are included to demonstrate the presentation of water-quality information.

pH

pH Level

Indicates how acidic or alkaline a water sample is.

NTU

Turbidity

Describes the cloudiness of water caused by suspended particles.

O₂

Dissolved Oxygen

Represents the oxygen available in water for aquatic organisms.

°C

Temperature

Shows water temperature, which can influence aquatic life and dissolved oxygen levels.

SYSTEM WORKFLOW

How the Proposed System Works

The following workflow describes the concept that the website is designed to demonstrate.

01

Data Collection

In a real implementation, sensors or water-sampling equipment would collect measurements.

02

Data Analysis

The collected readings would be checked against suitable environmental criteria.

03

Dashboard Display

Measurements and their interpreted status would be presented through a user-friendly dashboard.

04

Alert Generation

A connected system could notify users when validated readings require attention.

TECHNOLOGY STACK

Technologies Used

The current prototype is built using basic web development technologies.

HTML5

Structures the pages and their content.

CSS3

Controls the layout, colours, typography, and responsive design.

JavaScript

Supports interactive elements and simulated readings in the website.

Project Scope and Limitations

  • The website uses simulated readings for demonstration.
  • No real sensors, databases, or external lake-monitoring services are connected.
  • The displayed alerts and thresholds are illustrative and are not scientifically validated for a particular lake.
  • The prototype cannot confirm actual pollution levels or replace laboratory testing and environmental assessment.
